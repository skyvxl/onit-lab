## Границы решения

Это локальный учебный стенд: HTTP и Docker socket у доверенного runner. Для общего production-сервера потребуются TLS, изоляция сборщиков и отдельная схема доступа к деплою. Миграции должны сохранять совместимость с прежним приложением; откат приложения не откатывает схему БД. Необязательный Trivy не подключён.
